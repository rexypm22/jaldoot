## 🚀 Overview
**Jaldoot Response Hub** is an advanced disaster management and relief coordination platform specifically tailored for the challenging terrain and connectivity constraints of North-East India. It bridges the gap between emergency responders and affected zones by providing real-time situational awareness, resilient communication tracking, and localized data workflows.

---

## ✨ Key Features
* **Official MDoNER Emblem:** Integrated branding aligned with the Ministry of Development of North Eastern Region.
* **Mesh Network Widget:** Built for low-connectivity or internet blackout scenarios typical in hilly disaster-prone terrains.
* **Network Status Pill:** Real-time connectivity and telemetry monitoring for field teams.
* **Multilingual Selector:** Empowers local ground forces to coordinate in regional languages.
* **Command Center UI:** High-visibility dark theme (`dusk` palette) optimized for emergency operations centers.

---

## 🛠️ Tech Stack
* **Framework:** Next.js (React / TypeScript)
* **Styling:** Tailwind CSS & Custom UI components
* **Deployment:** Vercel (`https://jaldoot-three.vercel.app/`)

---

## 📊 Data Architecture & Roadmap
* **Water & Flood Telemetry:** Central Water Commission (CWC) standards
* **Geological Hazards:** Geological Survey of India (GSI) landslide tracking parameters
* **Workflows:** NDMA / State Disaster Management Authority guidelines
* **Database Strategy (Production):** PostgreSQL with PostGIS extensions for spatial mapping and real-time logs.

## 💻 Local Setup & Installation

To run this project locally on your machine:

```bash
# Clone the repository
git clone [https://github.com/rexypm22/jaldoot.git](https://github.com/rexypm22/jaldoot.git)

# Navigate to the project directory
cd jaldooot-response-hub

# Install dependencies
npm install

# Run the development server
npm run dev
